# Sprint_5
# Проект UI-автотесты для учебного сервиса «Доска»
выполнен на Python с использованием библиотеки Pytest и фреймворка Selenium

## Структура проекта:
* `tests/` — тестовые модули
* `src/` — локаторы, тестовые данные, генерация данных,конфигурация
* `conftest.py` — фикстуры (настройка драйвера, создание нового зарегистрированного пользователя)
* `.gitignore` — список игнорируемых файлов
* `README.md` — описание проекта

## Написаны тесты на функциональность:
* «Регистрация пользователя» - модуль test_signup.py -  тесты:
    * Регистрация пользователя
    * Регистрация пользователя c email не по маске
    * Регистрация существующего пользователя
* «Login пользователя» - модуль test_login.py -  тесты:
    * Login пользователя
* «Logout пользователя» - модуль test_logout.py -  тесты:
    * Logout пользователя
* «Создание объявления» - модуль test_postad.py -  тесты:
    * Создание объявления неавторизованным пользователем
    * Создание объявления авторизованным пользователем
